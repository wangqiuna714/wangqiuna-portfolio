王秋娜个人作品集网站

使用方法：解压后打开 index.html 预览。

公开发布至互联网：
1. 登录 GitHub，创建公开仓库，例如 wangqiuna-portfolio。
2. 上传本文件夹里的全部文件（包括 assets 文件夹）。
3. 打开仓库 Settings -> Pages。
4. 在 Build and deployment 中选择 Deploy from a branch，选择 main / (root)，保存。
5. 等待 GitHub Pages 给出公开网址：https://你的GitHub用户名.github.io/wangqiuna-portfolio/

注意：该网址是示例，不是已发布的网站。
